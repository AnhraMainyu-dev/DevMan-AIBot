# Чат-боты для общения с клиентами на платформах VK и Телеграм

Проект представляет собой чат-ботов для оптимизации службы поддержки любых сервисов. Боты обрабатывают наиболее типичные вопросы автоматически, обучаясь специфике конкретных сфер с помощью нейросетей.
Это позволяет значительно уменьшить нагрузку на операторов, позволяя им акцентировать усилия на наиболее сложных вопросах.

### Как установить
Для работы с ботами требуются API-ключи бота в телеграме (можно получить по адресу [@BotFather](https://t.me/BotFather)) и вашей группы в ВК (получаются в настройках вашей группы после выдачи всех нужных разрешений).

Они должны быть указаны в файле окружения .env в виде:
```
TELEGRAM_BOT_TOKEN=[API]
VK_API=[API]
```

Также для работы со скриптами и доступа к нейросети DialogFlow потребуются сервисный ключ нейросети от Google Cloud (можно получить по адресу [DialogFlow](https://docs.cloud.google.com/dialogflow/es/docs/quick/setup#sdk)) и ID вашего агента в сервисе DialogFlow.

Они должны быть указаны в файле окружения .env в виде:
```
GOOGLE_APPLICATION_CREDENTIALS=[Путь к файлу с ключом]
DIALOGFLOW_PROJECT_ID=[ID проекта]
```

Также для обработки логов требуются API-ключ бота в телеграме (можно использовать тот же) и ваш Телеграм ID (можно получить в [@UserInfoBot](https://t.me/userinfobot)).
Они должны быть указаны в файле окружения .env в виде:
```
TG_BOT_TOKEN=[API]
TG_USER_ID=[ID]
```

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, если есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

### Как использовать

Перед использованием боту нужно предоставить базу данных для обучения, чтобы он корректно обрабатывал соответствующие запросы от клиентов.
База данных является файлом `questions.json` в виде:
```
{
    "Тематика вопросов": {
        "questions": [
            "Вопрос1?",
            "Вопрос2?",
            ...
        ],
        "answer": "Ответ бота"
    },
}
```
Чем больше вопросов во всех возможных итерациях будет отправлено, тем более точно боты смогут идентифицировать запрос клиента.
Файл нужно расположить в корне проекта и отправить в DialogFlow командой:
```
python df_create_intent.py
```

Каждого бота можно запустить по отдельности.

Команда запуска бота для ВК:
```
python vk_bot.py
```

Команда запуска бота для Телеграм:
```
python tg_bot.py
```
